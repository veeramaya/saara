Use-case recipes

Short, do-this-then-that recipes for the jobs people reach for most.

Capture

A screenshot into an event

Turn a Zoom/Meet invite you were sent into a real calendar event.

  1. + Task → From a screenshot / photo
  2. Pick the invite image → choose Event
  3. AI fills the title, time and join link — check it against the image
  4. Release → it's on your Google Calendar
Perform

Run a 2-hour training live

Break a big event into a timed run-of-show you execute on stage.

  1. Create the event (2h) → open it
  2. Action items → add each segment with a start & duration (they chain automatically)
  3. On the day: Start agenda → tick Complete & next as you go
  4. Finish → review the Event report
Sync

Phone ↔ laptop, no cloud

Move your whole record between your own devices in seconds.

  1. Both on the same Wi-Fi
  2. Settings → Sync between my devices → Sync over Wi-Fi
  3. Laptop: Show a code · Phone: Scan a code
  4. They match — history, areas and all
Measure

A money goal, scored

Money is just a measurable — quantify it and it's real.

  1. Add a task like "Save ₹5,000 this month" in the Finance area
  2. Attach the number as a measurable result
  3. Hit the number → kept (+1); fall short → not kept. No grey zone.
Resolve

Untangle a clash

Two commitments overlap — decide honestly.

  1. Today shows "N overlaps ahead" → tap it
  2. See the clashing items side by side
  3. Keep one and Reschedule the other — cleanly, on the record
Invite

Invite someone on WhatsApp

Send a commitment as a beautiful card.

  1. Open the event → Share as card
  2. Pick Brand, optionally add an AI line
  3. Share card → WhatsApp — the join link stays tappable
