Saara for Windows

The desktop app — your whole record, on your PC. Local-first, private, no account required.

Download for Windows

Windows 10 / 11 · 64-bit

Install in three steps

  1. Click Download for Windows above and save the file.
  2. If you downloaded the .zip: right-click it → Extract All, then open the folder and run saara.exe. (If it's an installer .exe, just double-click it.)
  3. Saara opens. Your data lives only on your PC — nothing is uploaded.
"Windows protected your PC"? That blue box appears because the app isn't code-signed yet, not because anything's wrong. Click More info → Run anyway. (We're working toward a signed / Microsoft Store version so this goes away.)

Sync it with your phone

Already have Saara on Android? Open Settings → Sync between my devices → Sync over Wi-Fi on both, show the code on one and scan it on the other — your tasks, areas and history cross directly over your network. No cloud, no account.
